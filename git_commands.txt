# Git Commands Used in the Assignment

1. `git init -b main`  
   Initializes a new Git repository with the default branch named main.

2. `git config --global user.name "Rishikesh Wavdekar"`  
   Configures the Git username used for commits.

3. `git config --global user.email "2024eb01007@online.bits-pilani.ac.in"`  
   Configures the email address associated with commits.

4. `git status`  
   Displays the current state of the working directory and staging area.

5. `git add .`  
   Stages all eligible changes in the current directory.

6. `git commit -m "Initial project setup"`  
   Creates the first commit containing the initial project files.

7. `git add index.html`  
   Stages changes made to index.html.

8. `git commit -m "Update homepage"`  
   Saves the homepage update as a new commit.

9. `git branch feature`  
   Creates a new branch named feature.

10. `git switch feature`  
    Switches the working branch to feature.

11. `git add about.html`  
    Stages the new about.html file.

12. `git commit -m "Add feature page content"`  
    Commits the feature page changes.

13. `git switch main`  
    Switches back to the main branch.

14. `git merge feature`  
    Merges the feature branch into main.

15. `git log --oneline --graph --all`  
    Displays the commit history in a compact graphical format.

16. `git add .gitignore`  
    Stages the .gitignore configuration file.

17. `git commit -m "Add gitignore configuration"`  
    Commits the ignore rules.

18. `git commit -m "Add temporary homepage change"`  
    Commits a temporary homepage modification.

19. `git revert HEAD`  
    Reverses the most recent commit by creating a new commit, preserving the project history.

20. `git remote add origin https://github.com/2024eb01007-ctrl/Git_Assignment.git`  
    Connects the local repository to the GitHub remote repository.

21. `git remote -v`  
    Displays the configured remote repository URLs.

22. `git push -u origin main`  
    Pushes the main branch to GitHub and establishes upstream tracking.

23. `git push origin feature`  
    Pushes the feature branch to GitHub.

24. `git branch -a`  
    Lists all local and remote branches.
